# Test skeleton

Before expanding scope, add deterministic tests for the required demo scenarios:

1. grounded routine FAQ → `AUTO_REPLY`;
2. missing order/product detail → `ASK_CLARIFICATION`;
3. payment, refund, cancellation, or complaint threat → `ESCALATE`;
4. deadline and waiting-time signals → explainable high urgency;
5. seller approval or edit → audit event and updated status;
6. missing evidence or model failure → no invented answer.
